# Sources: `data/snowflake`

Every input to this analysis is an **existing public dataset or document**.
We made **no new measurements**: we did not resolve, probe or contact any front domain, broker, STUN server, proxy, bridge or blocked name.
No accounts, API keys or approvals were used.
All files were retrieved on **2026-10-03 between 21:46 and 21:53 UTC** by `fetch_raw.py`, with requests paced at least 1.5 s apart.
The per-file table below (URL, retrieval time, sha256, size, license) is generated from `raw/manifest.json`.

To reproduce, run these in `data/snowflake`:

```
cp raw/manifest.json manifest.paper.json   # keep the paper's manifest first
python3 fetch_raw.py --paper-commits --only collector tormetrics ioda gitlab lit
python3 analysis.py --no-fig               # rebuild derived/ from raw/ only (no network)
```

`raw/README.md` gives the full procedure and the check of the download against
`manifest.paper.json`, and `derived/README.md` lists the outputs and the check
of the rebuilt files.

### Deliberately not used

- **OONI `torsf`.** It is not usable as censorship evidence: the same test fails 97-100% of the time in uncensored countries (US, DE, IT) because ooniprobe's domain-fronting configuration is stale.
- **Russian registry dumps.** Not used by this analysis, and nothing from them was fetched.
- **Cloudflare Radar.** Needs an API token.
- **New in-country measurements.** Out of scope. The study makes no new measurements.

## Ethics and handling notes

- The front domains, AMP front and STUN hostnames in `derived/rdsys_*.csv` are copied from Tor's public configuration repository. They were never resolved or contacted. They are ordinary public websites and services, not illegal content.
- IODA, net4people, rdsys-admin and the two PDFs may not be redistributed (`redistribute: no` in the manifest). The artifact ships none of the raw files, and `fetch_raw.py` downloads them again. For the same reason it ships no `derived/rdsys_*.csv` table (rdsys-admin content), no `derived/shutdown_day_masks.csv` (daily IODA scores) and no `derived/ioda_long_events_not_used_in_primary_mask.csv` (IODA records). `analysis.py` writes these locally, and `derived/README.md` lists the derived files that ship.
- Everything derived from S1 and S2 is CC0-compatible. No OONI or OpenINTEL data are used here, so no share-alike obligation applies to this directory.
